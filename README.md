# 📖 About This Repository

Welcome to **100 Days of Pandas**, a structured learning journey designed to help you master one of the most important Python libraries for data analysis.

Rather than memorizing syntax, this repository focuses on solving practical problems inspired by real-world business scenarios. Every day introduces a new concept, followed by explanations, examples, coding exercises, and challenges to reinforce learning.

Whether you're preparing for data analytics interviews, transitioning into data science, or strengthening your Python skills, this repository provides a clear and consistent roadmap.

---

# 🎯 Goals

By the end of this challenge, you will be able to:

* Load and inspect datasets
* Clean messy data
* Handle missing values
* Filter and manipulate data efficiently
* Perform aggregations using `groupby`
* Merge and join datasets
* Create pivot tables
* Work with dates and time series
* Apply advanced Pandas techniques
* Solve real-world data analysis problems
* Build confidence for analytics interviews

# 🛣 Learning Roadmap

## Phase 1 — Foundations (Days 1–20)

* Installing Pandas
* Reading CSV, Excel, JSON
* Understanding Series & DataFrames
* Exploring datasets
* Indexing and selecting data
* Filtering rows
* Sorting data
* Renaming columns

---

## Phase 2 — Data Cleaning (Days 21–40)

* Missing values
* Duplicate records
* String operations
* Datetime handling
* Type conversion
* Feature engineering
* Outlier detection

---

## Phase 3 — Data Analysis (Days 41–60)

* GroupBy
* Aggregations
* Pivot Tables
* Crosstabs
* Correlation
* Ranking
* Window operations

## Phase 4 — Real-World Analysis (Days 61–80)
